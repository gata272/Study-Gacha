# スタディガチャ（StudyGacha）

勉強時間を記録するとコインが貯まって、ガチャが回せる、勉強のモチベーション維持アプリです。

## 遊び方

1. 「記録」タブで勉強を記録します
   - タイマー：科目を選んでスタート。計った時間をそのまま記録できます（他のタブに移っても進み続けます）
   - 手入力：時間（5分単位）と科目と日付を選んで記録。過去の分の後付け記録もできます
   - 科目は 国語／数学ⅠA／数学ⅡB／数学ⅢC／英語／化学／物理／社会／その他 の9つ
2. 記録するとコインがもらえます
   - 基本：1分 = 1コイン
   - 長時間ボーナス：30分以上 +10／60分以上 +20／120分以上 +50
   - 連続日数ボーナス：その日最初の記録で、連続日数 × 5コイン（最大+50）
3. 「ガチャ」タブでコインを使ってガチャを回します（1回100コイン／10連900コイン、10連はSR以上1つ確定）
4. 「バッジ」タブで集めたバッジを確認。全200種類コンプリートが目標です

## ガチャ仕様（バッジガチャ）

- 排出物は、小テストジェネレーター（アプリ『暗記カードと辞書』）の「バッジガチャ」を参考にしたコレクションバッジです
- 食べ物・キッチン用品をモチーフにした、ひらがな名前のバッジが全200種類（例：おにぎり、ふらいどぽてと、はんぶんのそーせーじ、にくをたたいてやわらかくするやつ）
- ウルトラレア以上は金色の「ゴールドバッジ」（★付きの名前、24種類）、それ以外は「標準バッジ」です
- レアリティと出現率：コモン 50%／レア 30%／スーパーレア 14%／ウルトラレア 5%／レジェンド 1%（種類数：コモン84／レア58／SR34／UR16／レジェンド8）
- ダブったバッジはレアリティに応じてコインに自動還元されます（5／15／40／120／400コイン）
- 10連は通常より100コインお得で、SR以上が1つ確定します
- 200種類＋ゴールドの少なさで、コンプリートにはかなりの勉強量が必要です
- バッジ図鑑では取得数・進捗%・ゴールド/標準の内訳が見られます

## その他の機能

- レベル：累計勉強時間10時間ごとにレベルアップ。レベルで称号が変わります（見習い→駆け出し→一人前→達人→探求者→マスター→勉強の神）
- ホーム：今日の勉強時間、連続日数、最近7日のグラフ、科目別の累計
- 履歴：最近の記録を確認・削除できます（削除すると時間とコインも取り消されます）
- データは端末内に自動保存されます。外部に送信されることはありません

## 注意

- タイマーはアプリを終了するとリセットされます（タブ移動では止まりません）
- 記録の削除でコインがマイナスになる場合は0で止まります

## ビルド方法（PC不要）

1. GHUploader で新しいリポジトリ（例：`StudyGacha`）を作成し、このZIPの中身をアップロードします（`.github` フォルダも含めてください）
2. GitHub Actions（macos-26）が未署名IPAをビルドします
3. 成果物 `StudyGacha-ipa` をダウンロードし、LiveContainer にインポートしてください
